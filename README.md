# Portafolio de Diego Sime

Sitio personal hecho solo con HTML y CSS, sin plantilla: https://diegosimemirror.github.io

| Archivo o carpeta | Qué contiene |
| --- | --- |
| `index.html` | Portada: presentación, proyectos, otros proyectos y participación |
| `estilos.css` | Colores, letras y tamaños; los parámetros están al inicio |
| `proyectos/` | Una página por proyecto |
| `imagenes/` | Foto y gráficos |
| `files/` | CV en PDF |
| `demos/` | Herramientas interactivas: incendios en Junín, mapeo de procesos del Estado e indicadores de salud de la OCDE |
| `portfolio/` | Redirecciones desde las direcciones de la versión anterior |
| `.github/workflows/publicar.yml` | Publica el sitio en GitHub Pages con cada cambio en `master` |

La versión anterior, hecha con la plantilla academicpages, está guardada en la rama `plantilla-academicpages`.
